## ✨ 功能特色

| | |
|---|---|
| 🌍<br>**全美<br>覆盖** | 全部 50 州，按东北、南部、中西部、西部、西南等区域排序。 |
| 🏙️<br>**推荐<br>城市** | 十二座城市卡片、评分、详情，以及直达天气工具的**实时天气**芯片。 |
| 🔗<br>**实用<br>外链** | 官方旅游、公共交通、公园与博物馆链接；部分导览区块另有精选链接。 |
| 🖼️<br>**相册** | 可筛选旅行相册：搜索、排序、画质（缩略图 / 中等 / 原图）*支持 HDR* |
| 🌄<br>**沉浸式<br>首页** | 全屏风格主图（经典 / 现代）、光暗蒙版与精致入场动效。 |
| 🎞️<br>**关于区<br>拼贴** | 三格相册缩略图轮播（偏重风景与地标），点击进入相册。 |
| 🧰<br>**旅行<br>工具** | 汇率、世界时钟、小费与销售税（50 州）、油车/电车费用、紧急电话与**实时天气**。 |
| 🌦️<br>**季节<br>文化<br>与<br>路线** | 何时出行、文化亮点与经典公路。 |
| 🎲<br>**美国<br>趣味<br>冷知识** | 每次随机一条，多语言支持 |
| 🌐<br>**多语言** | 英 / 西 / 中 / 日（含法律页）。 |
| ⚙️<br>**个性化** | 外观（系统 / 浅 / 深）× 风格（经典 / 现代）、语言、单位与相册画质——保存在本机。 |
| ♿️<br>**无障碍** | 三级动效：完整 / 减弱 / 关闭。设置「完整」优先于系统「减少动态效果」。光标拖尾可单独控制。 |
| 📱<br>**移动端<br>友好** | 首屏透明导航、底部布局与返回导览时的滚动恢复。 |
| 🔒<br>**隐私<br>与<br>条款** | 站内[隐私政策](https://travelusa.pages.dev/privacy.html)与[使用条款](https://travelusa.pages.dev/terms.html)，含外链说明。（法律文件的翻译仅供参考，以英文版为准） |
