## はじめに {#overview}

本サイトは **Tim G**（GitHub [@TGthms](https://github.com/TGthms)）が制作・運営する、個人プロジェクトの旅行ガイド兼フォトジャーナルです。基本的には静的サイトで、ページを開けばすぐ読めます。アカウント登録は不要です。

本ポリシーでいう「個人情報」とは、お客様を識別できる情報、または合理的に結び付けられる情報を指します。個人を特定できない集計データや、単なる技術ログは個人情報として扱いません。

## どのような情報が関わるか {#what-we-collect}

ご利用方法によって、次のような情報が関わることがあります。

- **設定として選んだ内容。**テーマ、言語、温度・距離の単位、天気関連の単位、動きやカーソルの設定、ギャラリー画質などは、ブラウザの保存領域（例：`localStorage`）に端末へ残ることがあります。サイトデータを消さない限り、その端末に保持されます。
- **任意の位置情報（天気ツールのみ）。**「現在地を使う」を選ぶと、ブラウザが許可を求めることがあります。予報に必要なのは**おおよその位置**です（番地レベルの精度は不要です）。送信前に端末上で座標を**約 1 km 程度**に丸めます。丸めた座標は天気データ提供元へ送られ、次回表示のため端末に保存される場合があります。精密な GPS 軌跡を当方のサーバーで受け取ることはありません。許可しなくても、都市名検索でご利用いただけます。
- **ブラウザやホスティング側の技術情報。**一般的なウェブサイトと同様、配信・セキュリティのため、IP アドレス、ブラウザの種類、アクセス先 URL などがホスティングや CDN で処理されることがあります。本サイトから広告用プロファイルを作成することはありません。
- **ご自身で送った内容。**メールや GitHub などでご連絡いただいた場合、そのメッセージに書かれた内容を受け取ります。
- **アカウントはありません。**ガイド・ギャラリー・ツールの通常利用に、登録やパスワード、支払い情報は不要です。

## 情報の利用目的 {#how-we-use}

- 同じブラウザで表示・アクセシビリティ設定を覚え直すため
- 通貨換算、天気予報、大気質などのツール提供のため（第三者 API を使う場合があります）
- ホスティング基盤を通じた配信・安全・安定運用のため
- お問い合わせへのご返信のため

個人情報を**販売することはありません**。本サイトの設定保存を、サイト横断の広告に使うこともありません。

## 情報の保存場所 {#storage}

設定データは**お客様の端末内**に保存されます。ホスティング事業者は、そのインフラがある地域で接続ログを処理する場合があります。GitHub Pages など公開ホスティング経由の場合、その事業者のプライバシー規約もホスティング部分に適用されます。

## 第三者サービス {#third-parties}

機能の提供にあたり、次のような第三者サービスを利用することがあります。

- **フォント。**多言語表示のため Google Fonts からウェブフォントを読み込むことがあります。IP などの技術情報が含まれる場合があり、Google の方針が適用されます。
- **為替（ツール）。**通貨換算は公開 API（例：Frankfurter）へレートを問い合わせることがあります。必要な通貨コードのみ送信します。
- **天気・警報・大気質（ツール）。**米国の予報と有効な悪天候警報は National Weather Service（api.weather.gov）から、世界の予報・補完データ・地名検索・大気質は Open-Meteo（または同等のサービス）から取得する場合があります。選んだ地点の座標や地名が含まれます。「現在地」利用時は、約 1 km に丸めたうえで送信します。天気・警報は旅行の参考情報であり、緊急時の公式情報の代わりにはなりません。悪天候時は当局の指示に従ってください。
- **ギャラリー。**写真・動画は本サイトの静的ファイルとして読み込まれます。別途の解析 SDK は不要です。
- **生成カード画像。**ホームページの一部カード背景は AI 生成の装飾イラストで、静的ファイル（`ai-images/`）として配信されます。読み込みによってあなたの写真やアカウント情報がアップロードされることはありません。[生成画像](#generated-images) もご覧ください。
- **外部リンク。**公式観光局、交通機関、国立公園、博物館、GitHub などへのリンクがあります。クリックすると本サイトを離れ、当方が管理しないサイトへ移ります。相手方のプライバシーポリシーが適用され、リンクは推奨を意味しません。

## 生成画像 {#generated-images}

ホームページの一部カード背景（地域、都市、季節、文化、ルート、必需品、ヒント）は、ギャラリーの実写ではなく、特定の私人を写した写真でもない **AI 生成の装飾イラスト**です。サイトの他のファイルと同様、静的ファイルとして配信されます。

ギャラリーは引き続き作者本人の旅行写真です。本サイトからこれらのイラストを表示しても、ギャラリー写真・位置情報・アカウントデータが画像生成サービスへ送られることはありません。

## Cookie とローカル保存 {#cookies}

本サイトは、広告 Cookie ではなく**ブラウザのローカル保存**で設定を覚えることを優先しています。ただし、セキュリティや負荷分散などのために、ブラウザやホストが Cookie 等を使う場合があります。ブラウザでサイトデータを消したり保存を制限したりできます。その場合、一部の設定は次回アクセス時に初期状態へ戻ります。

## お客様にできること {#choices}

- **設定**から、テーマ・言語・単位・動き・ギャラリー画質をいつでも変更できます
- ブラウザでサイトデータを削除し、端末上の設定を消せます
- 必要に応じて第三者フォントや API への通信を制限できます（一部機能が使えなくなる場合があります）
- プライバシーに関するご質問は、下記までお気軽にどうぞ

## お子さまについて {#children}

本サイトは一般的な旅行情報を提供するもので、13 歳未満（またはお住まいの地域で同等とされる年齢）のお子さまを対象としていません。故意に児童の個人情報を収集することはありません。お子さまの情報が提供されたと思われる場合はご連絡ください。適切に対応します。

## ポリシーの更新 {#changes}

本ポリシーは必要に応じて更新することがあります。更新時はページ上部の「更新日」を変更します。更新後も本サイトをご利用いただいた場合、更新内容をご了承いただいたものとみなします。重要な変更があるときは、可能な範囲でサイト上でもお知らせします。
